# 内容账号基建

核对日期：2026-09-17。用于店铺完成定位并准备商品上线时，建立可发布内容、挂商品和协作的账号基础。账号绑定方式、数量和权限以当前卖家中心为准。

## 固定顺序

1. 确认店铺官方号或渠道号的用途；
2. 按后台流程绑定正确账号；
3. 核对头像、名称、简介、语言和地区展示；
4. 检查商品橱窗、挂商品和直播权限；
5. 配置团队角色和最小必要权限；
6. 建立素材库、选题表和发布记录；
7. 发布测试内容，检查前台跳转和商品可售状态。

## 账号定位

账号内容必须与店铺主营类目、目标人群和价格带一致。新手先做一个主账号，不同时运营大量低质量账号。

简介写清卖什么、适合谁和主要场景。名称、头像和素材不得使用未授权品牌、人物或商标。

## 内容基础库

为每个测试商品准备：

- 商品实拍、细节、尺寸和包装素材；
- 痛点、场景、演示、对比和教程角度；
- 常见问题、客服反馈和评论选题；
- 可使用的音乐、字幕、翻译和授权记录；
- 原始文件、剪辑版本、发布时间和数据结果。

## 权限与安全

- 主账号开启可用的安全验证；
- 团队成员使用子账号或平台提供的协作权限；
- 不共用密码、验证码和恢复信息；
- 达人素材必须保存授权范围和有效期；
- 人员离开后立即收回权限。

## 完成标准

官方号或渠道号绑定正确；账号资料与店铺定位一致；商品挂载和前台跳转正常；团队权限和首批素材已经准备。完成后进入定价、营销和首月启动。
