# TikTok 运营阶段与实时资料机制

## 目标

基础设备、网络和 IP 配置完成后，进入 TikTok 运营阶段。这个阶段不要求另行建立一套固定运营教程，学员遇到运营问题时只走两条路径：

1. 直接与船长 Chris 或工作人员对接提问；
2. 由 AI 根据学员的问题、截图和最新可靠资料进行查询并答复。

这两条路径同样适用于真实故障处理。AI 负责先判断问题、收集必要证据和给出下一步；需要业务判断、账号处理或人工确认时，直接转交工作人员。

运营阶段可以协助处理：

- 账号登录和基础资料设置；
- 头像、昵称、用户名、隐私和账号类型；
- 浏览、搜索、收藏、关注、点赞等基础功能；
- 发作品、作品可见性、审核和推荐资格；
- 0 播放、无法互动、无法换头像等现象的证据化诊断；
- 根据学员截图和官方规则，给出可执行的下一步。

本阶段不承诺播放量、解封、恢复互动或进入推荐，也不协助刷量、批量养号、伪造身份地区、操纵互动或规避平台风控。

## 手机设置执行规则

定位、分析数据、隐私、App 权限、后台刷新等手机设置，按照已经提供的手机设置 SOP 和对应截图执行。不要把这些设置重新列为待补充资料，也不要凭经验改写开关状态。

如果学员遇到的是截图中没有覆盖的页面，或 AI 无法看清当前页面，只要求学员上传当前页面的打码截图，再判断下一步。

## 深问必查机制

满足以下任一条件时，AI 必须先查询最新、可靠的公开资料，再回答：

- 学员追问“为什么”“依据是什么”“官方怎么说”；
- 问题涉及账号处罚、内容下架、推荐资格、申诉、商业内容披露或地区功能；
- 规则可能随时间、国家/地区、账号类型或产品版本变化；
- AI 不能从当前截图确定原因；
- 学员连续两轮追问仍不接受初步判断；
- 学员明确要求“详细诊断”“查官方资料”或“给我可靠说法”。

### 资料来源优先级

1. TikTok 官方帮助中心、社区自律规范、账号状态和申诉页面；
2. TikTok 官方创作者或商业资料；
3. Apple、Google、Shadowrocket、IP 服务商等产品官方文档；
4. 监管机构、大学论文或行业研究；
5. 其他资料只能作为背景，不作为单独结论。

回答中必须注明：

```text
查询日期：
资料来源：
适用范围：
官方明确说明：
结合当前截图的判断：
仍然不能确定：
```

如果官方资料没有回答，不得把论坛经验写成官方规则，应明确说“官方资料未能确认”，然后转为补充证据或联系官方支持。

## 运营阶段问诊入口

收到学员问题时，先让其提供以下最少信息：

- 手机型号和 iOS 版本；
- TikTok App 版本；
- 当前 Shadowrocket 是否连接；
- 当前 IP 检测是否通过；
- 问题发生的具体时间；
- TikTok 页面原文或错误提示；
- 相关页面打码截图；
- 这是单个作品、单个功能，还是整个账号都异常。

不要要求发送密码、验证码、完整订阅链接、代理认证参数、恢复码或支付信息。

## 基础操作范围

### 账号和资料

先按 TikTok 当前页面操作，不凭旧版本路径硬指导。常见入口包括：

```text
Profile
→ Edit profile
→ Change photo / Name / Username
```

每次只修改一项，保存后截图确认。账号为公开还是私密、个人/创作者/商业账号等设置，要结合目标和官方当前页面判断。

### 发作品

先确认：

- 作品是否完成上传和处理；
- 作品可见范围；
- 是否出现审核、违规或“不适合推荐”等原文提示；
- 账号状态是否有警告；
- 内容是否属于商业推广并需要披露；
- 是否存在版权、重复搬运或其他内容资格问题。

0 播放不能直接归因于 IP。必须先区分上传失败、作品不可见、审核中、推荐不合格、账号受限和统计延迟。

### 互动功能

对于不能点赞、关注、收藏：

1. 区分按钮无响应、报错、暂时限制和账号整体限制；
2. 记录 TikTok 原文提示；
3. 检查账号状态、网络连通性和 App 版本；
4. 只做一个低风险测试；
5. 如果平台明确提示限制，优先使用官方申诉或支持入口。

不要用批量点击、换设备、换 IP 或互刷测试来“验证”限制。

## 故障诊断顺序

1. **平台页面**：原文提示、作品可见性、账号状态；
2. **应用层**：App 版本、权限、缓存、上传状态；
3. **设备层**：系统、时间、存储、相册权限、摄像头和网络权限；
4. **网络层**：Shadowrocket 状态、Proxy 模式、IP 归属、DNS/WebRTC/IPv6；
5. **内容层**：原创性、版权、商业披露、社区规则和推荐资格；
6. **官方处理**：申诉、工单或 TikTok 支持。

每次只修改一个变量。连续三轮无法确认时，整理证据并转交船长 Chris。

## 运营阶段输出格式

```text
目前判断：
官方依据：
还缺什么：
现在只做：
你应该看到：
如果不是这样：
不要发给我：
```

## 版本和地区提醒

TikTok 的功能入口、可用资格、商业披露要求、推荐资格和申诉路径可能因版本、国家/地区、账号类型和时间不同而变化。涉及这些内容时，回答必须带查询日期，必要时重新查询，不能沿用未经核验的旧 SOP。
