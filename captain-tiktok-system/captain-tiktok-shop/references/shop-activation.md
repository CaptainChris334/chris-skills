# 审核通过后的店铺启用

核对日期：2026-09-17。默认场景：中国大陆主体的 TikTok Shop 东南亚跨境自运营店。

## 优先级

按“能否开店 → 能否收款 → 能否履约 → 能否展示”的依赖顺序执行。不要先花大量时间做海报，再补收款和仓库。

### P0：确认店铺已可运营

1. 核对主体、开通市场、店铺状态和后台待办。
2. 按后台要求缴纳保证金，或确认当前店铺确实获得保证金豁免及到期日。
3. 使用专用邮箱，开启平台提供的安全验证；团队成员使用子账号和必要权限，不共用主账号密码。

### P1：绑定结算账户

1. 进入财务或结算设置，选择后台当前支持的结算服务商。
2. 按店铺主体及服务商要求完成实名和账户绑定。
3. 核对账户持有人、币种、提现路径、服务费和汇率，不因宣传页写“低费率”就跳过实际到账测试。
4. 绑定完成后保存成功页面，不发送完整银行卡号或认证资料。

东南亚跨境店当前官方资料列出的结算工具包括 Payoneer、连连国际、PingPong、Airwallex 和万里汇。工具名单、到账时间和费率可能变化，回答时查当前后台。

### P2：确定履约模式并设置仓库

先选择实际使用的模式，再绑定地址：

#### 中国直发

- 设置真实发货仓、联系人、电话和揽收地址；
- 选择平台当前支持的上门揽收、自寄或送至集货点方式；
- 核对面单打印、包裹尺寸重量、禁限运品和首公里截单时间；
- 设置实际可接收退件的退货方案。

#### 海外仓或当地仓

- 只有已经在目标国家备货，并且仓库能提供真实地址、库存和履约服务时才绑定；
- 优先核对平台官方认证仓或平台支持的仓库模式；
- 确认入库、库存同步、尾程、退货、丢损赔付和费用；
- 不把“绑定海外仓”当成所有新店的必做项。没有海外库存就使用中国直发流程。

仓库设置完成后做一次桌面验收：确认商品重量和库存能填写、物流方式能选择、面单能生成、包裹能在要求时效内进入平台物流链路。没有真实订单时不要制造虚假订单。

### P3：完成基础店铺形象

在选品前只做不依赖具体商品的基础装修：

- 确认店铺名称简短、可读，并与准备经营的方向不冲突；
- 上传清晰 Logo，避免未经授权的品牌名称、商标和人物素材；
- 填写简短店铺介绍和必要的客服信息；
- 按实际需要绑定店铺官方号或渠道号；
- 检查前台展示语言、名称和头像。

不要在类目和产品尚未确定前制作大量首页横幅、商品分类和促销素材。选品完成后，再按目标人群、价格带和核心商品完成正式装修与陈列。

### P4：开卖前验收

确认以下项目后进入选品：

- 店铺状态正常，没有未处理的入驻待办；
- 保证金或豁免状态明确；
- 结算账户显示绑定成功；
- 发货仓、揽收方式和退货方案可执行；
- 店铺名称、Logo和介绍已完成基础设置；
- 团队知道订单通知、客服和异常由谁处理。
