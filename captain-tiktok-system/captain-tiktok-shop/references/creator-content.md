# 内容、达人联盟与冷启动

核对日期：2026-09-17。用于商品卡验收后取得第一批真实流量和成交信号。达人联盟入口、准入、佣金、样品规则和可用功能会按市场变化，操作前读取当前卖家中心。

## 先判断资源

- 没有稳定内容团队：先开达人联盟并建联达人，同时补少量自营素材；
- 能稳定拍视频：自营内容和达人合作同步测试；
- 有成熟直播团队：先完成商品卡、脚本、样品和履约验收，再排直播；
- 没有可用素材、利润或库存：先补齐，不进入投流。

冷启动的目标是用低风险测试找到“商品＋素材角度＋达人类型＋价格”的有效组合。

## 自营内容测试

每个测试商品准备不同角度：痛点或场景、功能演示、前后对比或结果、细节教程、用户疑问或评论回复。每条内容只突出一个核心卖点，前几秒直接展示商品、问题或结果。挂正确商品，检查商品卡、价格、库存和地区可售状态。只使用自有或获得授权的音乐、图片、视频和达人内容。

按“曝光 → 停留/观看 → 商品点击 → 加购 → 成交 → 退款”判断，不只看播放量：

- 高播放低点击：改卖点、画面和挂链；
- 有点击无加购：查商品卡、价格和信任；
- 有加购无成交：查运费、优惠、交付和支付；
- 有成交高退款：停放量，查产品和描述。

## 达人联盟设置

1. 选择已通过商品卡和利润验收的商品；
2. 设置公开合作，写清卖点、目标人群、佣金和样品规则；
3. 对高匹配达人发起定向合作；
4. 佣金低于可承受上限，并为退款、广告和优惠留利润；
5. 寄样前确认库存、物流、内容要求和负责人；
6. 保存达人授权状态，未获授权不得擅自用于广告或其他渠道。

不要用统一高佣金替代商品竞争力。不要承诺达人一定出单，也不要要求虚假评价、刷单或隐藏商业合作。

## 筛选达人

优先看近期内容和实际匹配，不只看粉丝数：

- 内容垂类和受众国家；
- 近 30–90 天发布稳定性；
- 商品点击、成交和平均表现是否来自多个作品；
- 历史带货价格带；
- 评论真实性和购买讨论；
- 内容表达、画面和人设；
- 履约记录、样品发布率和响应；
- 异常粉丝、异常互动、侵权或违规记录。

课程方法：把达人分成小体量高匹配、中腰部稳定带货和少量头部测试，不把预算押在一个达人身上。

## 建联话术结构

> 你好，我看了你关于【具体内容/场景】的视频，和我们的【商品】受众很匹配。
> 商品核心卖点是【一个清楚卖点】，成交价约【价格】，可提供【佣金/样品】。
> 如果你有兴趣，我可以马上发商品资料和合作邀请。

说明为什么找这个达人，不群发无关长文。合理跟进，连续无回复就停止，不骚扰。

## 寄样管理

记录达人、商品/SKU、样品成本、物流单号、签收、承诺内容、预计发布时间、发布链接、点击、订单、退款、佣金和复投结果。

寄样前确认匹配度、平台允许的地址流程、库存补货、内容要求和高成本样品审核。不自动通过所有申请，不强迫达人照稿。

## 测试与淘汰

按漏斗定位问题：

- 已联系 → 回复：话术和匹配；
- 回复 → 接受：商品、佣金和信任；
- 接受 → 签收：样品与物流；
- 签收 → 发布：跟进和内容意愿；
- 发布 → 点击：选题、开头和卖点；
- 点击 → 成交：商品卡、价格和信任；
- 成交 → 净利润：佣金、退款和履约。

优先复投能持续发布、带来有效点击、成交和低售后的达人。只有播放没有点击或成交时，不因粉丝多就持续寄样。

## 冷启动通过标准

不写死统一订单数。满足以下证据后进入付费放大：

- 商品卡能正常转化；
- 出现可复现的有效素材或达人内容；
- 点击、加购或成交不是单次异常；
- 完整贡献利润为正；
- 库存、补货、发货、客服和退货能承接；
- 没有待解决的违规和高退款问题。

证据不足时继续改商品卡、价格、内容或达人组合，不用广告掩盖基础问题。
