# 第二阶段：电脑端与 Google 工具准备

## 使用原则

核心顺序、状态迁移、跳过和结束条件以本模块 SKILL.md 及总入口为准。开场使用总入口的纯动作清单，实际执行每次仅展开当前节点。仅答当前动作和相关故障；框架外问题按总入口固定拒答，转【船长电商】工作人员。粉猫安装、树洞购买、订阅导入与节点配置由使用 AI 前的准备阶段处理，不在此默认流程重教或逐项验收。

所有网址都让学员复制到电脑浏览器地址栏打开，不要求直接点击聊天链接。已有浏览器可用就先使用；Windows 可用 Edge，Mac 可用 Safari。Chrome 安装后统一使用 Chrome。接受明确文字确认；仅页面不明或报错需要时索取打码截图。不得收账号密码、验证码、恢复码、完整订阅链接、节点密码或二维码。

## P16：确认 Google 可以打开

爱思助手下载完成后，只发送当前确认步骤：

> 接下来：确认 Google 能否打开。
>
> 请在电脑上打开平时使用的浏览器，在地址栏输入 google，找到并打开 Google 网站。
>
> 如果不知道哪个是 Google，请把下面的网址复制到地址栏打开：
>
> https://www.google.com
>
> 看到 Google 页面后，请回复：Google 可以打开。
>
> 注意：只在百度或必应中搜到“Google”的介绍或链接，不代表已经打开 Google。打不开时告诉我具体提示，或发打码截图。

本步只确认网站可访问，不要求登录 Google 账号，不要求已安装 Chrome，不另查设备芯片或粉猫配置。已有明确的可访问反馈直接复用。确认通过才进入 P17，不同时发购买账号任务。

打不开时按 SKILL.md 进入当前故障排查。先区分普通网页是否也打不开，再根据实际提示读取 clients.md；一次只给一个相关动作。不得以故障为由重新执行整套安装、套餐购买或手机网络配置，故障解决后回到本步。

## P17：下载 Chrome 谷歌浏览器

必须先说明：**Chrome 就是谷歌浏览器，接下来下载安装它。**

用电脑当前浏览器，把下面地址复制到地址栏打开：

https://www.google.cn/chrome/

选择适用于本机系统的下载入口，完成安装包下载。如果需要区分 Windows/Mac，已有系统信息直接复用；未知时只问当前选择所需的信息。不因下载 Chrome 恢复已撤出的粉猫芯片核对流程。官网界面或版本选项不明时依据打码截图或官方资料核对，不猜按钮位置。

下载完成请回复：Chrome 安装包已下载。

若学员明确 Chrome 已安装并能打开，记录实际已有结果，进入 P19，不重装；不要强制其再次证明历史下载。

## P18：安装并打开 Chrome

- Windows：打开刚下载的 Chrome 安装程序，按提示完成安装，再打开 Chrome。
- Mac：打开刚下载的 .dmg，把 Google Chrome 拖入“应用程序”，再从“应用程序”打开。

只提供符合学员系统的一条路径。尚不明确系统时只问系统，不凭其他学员或旧模拟的设备信息猜测。

完成后回复：Chrome 已安装并打开。

“下载好了”不等于安装完成。出现系统警告时先看原文，不默认关闭安全保护。确认 Chrome 能打开后进入 P19，不额外重复网络配置检查。

固定话术结束。等待用户确认后才进入 P20；已有明确购买结果时不要求重复购买。不再附其他购买网址或购买条件，不臆造教程正文。教程打不开或购买有卡点时才按实际问题答疑，不自动退回旧购买网站流程。全局敏感信息保护规则继续生效，不索取密码、验证码或恢复码。

## P21：登录 Google

让学员在自己的 Chrome 中使用已完善的账号完成登录。需要登录地址时提供：

https://accounts.google.com/

收到“Google 已登录”等明确反馈后再进入下一步，不让学员发送认证资料。

## P22：登录 NotebookLM

让学员把下面网址复制到 Chrome 地址栏打开，使用已经完善并登录的 Google 账号：

https://notebooklm.google.com/

登录成功后回复：NotebookLM 已登录。页面不明或报错时才要求打码截图，不把登录成功自动等同于整体验收通过。

先复用已有依据，只确认当前仍缺少的实际结果：手机已准备好、爱思助手已下载、本机 Google 可访问、Chrome 已安装可打开、Google 账号已购买并修改资料、Google 已登录、NotebookLM 已登录。

不索取粉猫安装包、树洞购买、订阅导入、节点、系统代理、统一延迟的补充证明；这些已不是对话中的必需验收项。不要在验收时重新加回整套网络流程，也不要启动手机刷机。
