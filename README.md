# chris-skills

船长 TikTok Skills 2.0。

## 安装

    npx -y skills add CaptainChris334/chris-skills -g --skill "*" --agent codex -y

## 功能模块

- 船长 TikTok 总入口
- iPhone 设备、爱思助手与用户主动提出的刷机
- 电脑端粉猫、树洞、Chrome、Google 账号与 NotebookLM
- 美国 Apple ID、App Store、礼品卡与 Shadowrocket
- Shadowrocket、树洞订阅、Socks5 与 Proxy Pass
- IP 购买与 IP 检测
- TikTok Shop 0—1 开店与运营
- TikTok 运营故障诊断
- Skill 治理、版本保护与回滚

## 版本
