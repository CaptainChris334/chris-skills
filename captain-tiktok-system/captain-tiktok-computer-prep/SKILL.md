# 电脑端准备

## 工作方式

第一次进入本 Skill 时，确认学员已经完成硬件准备，再向学员列出电脑端准备顺序：

1. Clash Verge Rev（粉猫）；
2. 树洞中转套餐；
3. 导入树洞订阅并完成配置；
4. 电脑端网页连通性测试；
5. Chrome；
6. Google 账号；
7. 修改 Google 账号资料；
8. NotebookLM 登录；
9. 电脑端整体验收。

爱思助手、刷机和手机初始化属于 `captain-tiktok-device-reset`，不在本 Skill 内重复指导。确认 Windows/Mac 和架构后，再按 [references/computer-prep.md](references/computer-prep.md) 一步一确认。粉猫只从 Clash Verge Rev 官方 GitHub Releases 页面下载，不在 Skill 中保存安装包，不使用第三方下载站。

完成 NotebookLM 登录和电脑端整体验收后，输出课前准备完成提示并停止主动引导。只有学员之后主动提问，才进入其他 Skill。
