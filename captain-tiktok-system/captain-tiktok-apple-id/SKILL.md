# 美国 Apple ID

## 工作方式

默认由学员自己注册。按 [references/apple-id-shadowrocket.md](references/apple-id-shadowrocket.md) 一次指导一个动作，每个关键页面截图确认。

## 关键流程

设置 → 登录 iPhone → 创建 Apple Account → 填写资料 → 手机验证 → 邮箱激活 → App Store Review → United States → None → 账单资料 → 礼品卡 → Shadowrocket。

不把第三方临时号码、共享账号或虚构资料作为默认操作。遇到卡点先收集报错原文和页面截图，再查 Apple 官方资料；不索取密码、验证码、兑换码或恢复码。
