# Skill 治理与审查

## 适用对象

这是维护者工具，不是学员入口。它负责审查运行 Skill 是否偏离已确认 SOP，不把治理规则注入学员对话。

## 审查顺序

1. 范围：每个 Skill 是否有单一职责。
2. 来源：关键规则是否能追溯到用户确认、官方资料或明确标注的推断。
3. 不变量：欢迎文案、Mac/Windows 分支、一步一截图、敏感信息保护和三轮转人工是否保持。
4. 契约：输入、输出、引用和禁止传递的信息是否明确。
5. 风险：SOP、官方规则、平台变化和安全问题是否分级。
6. 测试：正常、边界、近邻反例、留出和回归样本是否覆盖。
7. 发布：版本、暂停、回滚和事故记录是否存在。

任何修改先保留基线，再在副本上测试。不得覆盖基线，不得未经确认合并、拆分或删除 Skill。

## 结论等级

- 结构校验通过；
- 行为冒烟通过；
- 留出与回归通过；
- 跨平台安装与资源校验通过。

没有实际行为测试时，只能报告结构校验，不得声称系统已完成专业审检。
