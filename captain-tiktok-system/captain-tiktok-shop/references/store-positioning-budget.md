# 店铺定位与启动资金

核对日期：2026-09-17。用于店铺完成基础启用后、进入正式选品前，确定店铺经营边界和可承受预算。

## 店铺定位

依次确定：

1. 服务哪个国家和哪类消费者；
2. 主营什么一级类目和使用场景；
3. 主成交价格带；
4. 用户为什么选择本店：功能、设计、套装、价格、内容、交付或售后；
5. 首批只测试哪些商品，不做哪些类目。

新手先做一个主要类目和一个清楚价格带。营业执照经营范围可以较宽，店铺前期定位不要无限扩散。

## 商品结构

课程方法：把计划中的商品分为测试款、主推款、利润款和连带款。开店初期不要求四类齐全，先用少量测试款验证，再根据真实订单补结构。

## 启动资金分配

至少建立以下预算项：

- 保证金和平台必要费用；
- 样品、检测和包装；
- 首批库存与补货；
- 国内段、跨境或当地物流；
- 达人寄样和佣金；
- 内容拍摄、翻译和剪辑；
- 广告和直播测试；
- 退款、退货、破损和汇率；
- 税费、工具和其他固定支出；
- 不用于投流的应急周转金。

## 三条资金红线

1. 不用生活必需资金压库存或投广告；
2. 不把平台补贴和未结算收入当作可用现金；
3. 先设单品、单日和首月最大可承受亏损，达到就停止并复盘。

## 现金流判断

用保守值计算：

可用运营资金 = 当前可投入现金 - 保证金 - 已承诺库存与物流 - 退款售后准备金 - 固定费用。

再根据采购付款时间、发货时间、平台结算时间和补货周期判断是否能周转。利润为正但现金回款慢，也可能无法持续补货。

## 完成标准

- 目标人群、主营类目、价格带和差异点已确定；
- 首批测试商品数量可控；
- 各预算项和最大亏损线已记录；
- 仍有足够资金处理补货和退款。

完成后进入专业选品。
