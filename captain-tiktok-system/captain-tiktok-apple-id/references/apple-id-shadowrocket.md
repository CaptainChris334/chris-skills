# 美国 Apple ID 与 Shadowrocket

## 使用说明

这份流程用于准备美国区 App Store 账号，以下载 Shadowrocket（小火箭）。AI 必须一次只指导一个动作，关键页面完成后让学员上传打码截图，再继续下一步。

流程中的账号、手机号、邮箱、付款资料和兑换码都属于学员个人敏感信息，禁止发送给 AI。

## 目标

由学员自己注册一个长期可控的美国 Apple ID，用于在美国区 App Store 下载 Shadowrocket（小火箭）。AI 一次只指导一步，每个关键页面让学员上传打码截图确认。

## 一、注册前准备

- 一个本人可以长期登录和收验证码的邮箱；
- 一个本人长期可控、能够接收验证码的手机号；
- 真实姓名和真实出生日期，年龄应符合 Apple 的账号要求；
- 用于购买 Shadowrocket 的有效付款方式或美国区 Apple Gift Card。

截图中出现了第三方短信验证平台的示例。该方式不作为推荐流程：临时号码、共享号码和不可控恢复信息可能导致账号无法验证、无法找回或被锁定。学员应使用本人长期控制、能够接收验证信息的联系方式。

账单地址、姓名和其他账号资料必须按 Apple 页面要求填写真实、可验证且由学员本人负责的信息，不使用随机生成或虚构资料。

## 二、在 iPhone 设置中创建 Apple ID

1. 打开 iPhone 的“设置”。
2. 点击顶部“登录 iPhone”。
3. 点击“没有 Apple ID 或忘记了？”一类入口。
4. 选择“创建 Apple ID / Create Apple Account”。
5. 填写姓名和出生日期，确认年龄信息符合 Apple 要求。
6. 填写本人长期可用的邮箱，邮箱会作为 Apple ID。
7. 设置高强度且未在其他网站重复使用的密码。
8. 填写本人长期可控的手机号，按页面完成短信验证。
9. 阅读并同意条款。
10. 打开邮箱，查收 Apple 验证邮件，点击邮件中的验证入口或填写验证码。
11. 回到 iPhone，确认邮箱和手机号验证完成。

### 每一步的截图要求

- 进入创建账号页面后：上传页面截图，遮住已有个人信息。
- 手机号验证页面：上传页面截图，遮住手机号和验证码。
- 邮箱验证完成后：上传成功页面或设置首页截图。

截图时必须遮住邮箱、手机号、密码、验证码、恢复信息和付款信息。

## 三、完成美国区 App Store 资料

1. 打开 App Store。
2. 点击右上角头像。
3. 如果出现 `Review`，点击进入检查页面。
4. 确认国家/地区选择为 `United States`。
5. 付款方式按页面要求选择 `None`，如果页面允许跳过付款方式。
6. 填写账单资料。资料必须真实、有效并符合 Apple 当前页面要求，不使用随机地址。
7. 点击 `Next` 或页面底部继续按钮，完成商店资料。
8. 返回 App Store 首页，确认可以搜索美国区应用。

如果无法选择美国区、付款资料不通过或提示账号地区异常，先截图进入诊断，不要连续修改地区和地址。不要为了通过审核反复尝试虚假资料。

## 四、充值美国区 App Store 余额

1. 打开 App Store。
2. 点击右上角头像。
3. 点击 `Redeem Gift Card or Code`。
4. 选择 `Enter Code Manually`。
5. 输入适用于美国区的礼品卡兑换码并确认。
6. 检查账户余额是否增加。

只使用来源可靠、适用于美国区 App Store 的礼品卡。不要购买明显低于面值、多人共享或来源不明的兑换码。不要把礼品卡兑换码发给 AI；如果需要诊断，只上传打码后的结果页面。

## 五、下载 Shadowrocket（小火箭）

1. 在 App Store 搜索 `Shadowrocket`。
2. 核对开发者为 `Shadow Launch Technology Limited`。
3. 核对应用名称和图标，避免下载仿冒软件。
4. 确认账户余额或付款方式足够支付当前页面显示的价格。
5. 点击价格按钮，使用 Face ID、Touch ID 或 Apple ID 密码由学员本人确认。
6. 等待下载和安装完成。
7. 打开 Shadowrocket，并上传首页截图。

Shadowrocket 和“小火箭”是同一个 App，不需要分别下载。价格可能变化，以 App Store 当时显示为准，不在 Skill 中承诺固定价格。

## 六、常见问题

- **收不到验证码**：确认邮箱/手机号可用、时间设置正确，等待后重试；不要连续申请大量验证码。
- **账号创建失败**：上传原文提示，检查网络、邮箱、手机号和设备时间。
- **账号被锁或无法使用**：停止反复登录，使用 Apple 官方账号恢复或支持流程。
- **App Store 不是美国区**：先确认账号国家/地区，不反复切换商店。
- **礼品卡无法兑换**：确认礼品卡地区、兑换码状态和账号地区一致，联系售卡方或 Apple 支持。
- **搜不到 Shadowrocket**：确认 App Store 国家/地区，并上传搜索结果截图。
- **余额不足**：补充可靠来源的美国区礼品卡或有效付款方式。
- **提示需要 Review 或完善资料**：按页面逐项完成，上传结果截图，不要反复切换国家/地区。
- **注册后无法找回账号**：停止继续修改，使用 Apple 官方账号恢复流程；如果账号来自第三方，不要把密码或恢复码发给 AI。

### 卡点查询规则

1. 先让学员提供报错原文、当前页面和已经完成的步骤。
2. 优先查 Apple 官方支持文档、Apple 官方账号恢复或付款支持页面。
3. 将查询结果转成当前设备可执行的一步操作，再让学员截图确认。
4. 如果官方要求联系 Apple 支持、验证身份或处理付款争议，停止继续试错并转人工。
5. 不使用来源不明的注册教程、临时接码教程、虚构地址教程或共享账号教程替代官方流程。
