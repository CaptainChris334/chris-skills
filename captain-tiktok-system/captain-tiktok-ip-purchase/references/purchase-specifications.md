# IP 购买规格

## 服务商选择

- 东南亚地区：优先 `911Proxy`。
- 欧美地区：优先 `Miya` 或 `IPRoyal`。

## 下单前核对

- 目标国家/地区；
- 州、省或城市；
- 静态住宅或 ISP 类型；
- ASN 类型；
- 独享；
- IP 数量；
- 有效期；
- 协议、端口、认证方式和异常更换规则。

优先目标地区匹配、长期稳定、独享的静态住宅或 ISP IP。出现 `Hosting`、`Datacenter`、`Cloud` 或 `VPS` 时，先确认是否选错产品。

## 购买后

服务商通常提供 `Address`、`Port`、`Username`、`Password` 和协议类型。只确认字段是否齐全，不要求把完整参数发给 AI。质量检测由 `captain-tiktok-ip-diagnostics` 负责。
