# 手机设备、刷机与初始化

## 设备选择

- 优先推荐业务中常见、稳定的 iPhone 11。
- 美版优先，但不是绝对要求；国行也可以。
- 不购买监管机、被标记过或有异常记录的设备。
- 购买前向供应商确认设备状态。
- 检查电池、摄像头、麦克风、扬声器、触屏、Wi-Fi 和系统。
- 无实体卡槽可以接受；本流程使用邮箱注册 TikTok，不依赖 SIM 卡短信。
- 手机仍必须能正常连接 Wi-Fi。

## 爱思助手刷机

官网：

```text
https://www.i4.cn
```

1. 在电脑浏览器中复制并打开爱思助手官网。
2. 选择 Windows 电脑版安装包并完成下载；此步骤不需要先判断 Windows 是 x64 还是 ARM64。
3. 打开安装包并完成安装。
4. 用数据线连接手机和电脑。
5. 手机出现“信任此电脑”时，由学员本人确认。
6. 确认爱思助手识别手机，进入“智能刷机”。
7. 选择对应系统版本；没有明确要求时不选择测试版。
8. 在“是否保留数据资料”中选择“清空”。
9. 点击“开始刷机”。
10. 在确认窗口核对设备、系统版本和“清空”，点击“立即刷机”。
11. 等待下载和刷机完成，不拔数据线、不关闭软件、不让电脑休眠。

“清空”会删除手机本机数据。开始前必须备份重要资料，并确认设备属于学员本人或已获授权。

## 刷机成功验收

电脑端出现以下界面才算刷机成功：

- 绿色对勾；
- 进度条完成；
- 显示“恭喜您，刷机成功啦～”；
- 右下角出现“完成”按钮。

学员先上传截图，确认后点击“完成”，再进入手机设置。

## 刷机后的手机设置

手机出现“你好”后：

1. 选择语言。
2. 选择国家或地区。
3. 连接可用 Wi-Fi，等待激活。
4. 在“数据与隐私”页面点击“继续”。
5. 如果出现快速开始，选择手动设置，不从其他手机传输数据。
6. 在“App 与数据”页面选择“不传输 App 与数据”。
7. Apple ID 页面按 `captain-tiktok-apple-id` 流程处理。
8. 定位、分析数据、隐私、App 权限和后台刷新等设置，按已确认的手机设置 SOP 和截图执行。
9. 完成设置，进入桌面。

## 桌面验收

进入桌面后：

1. 打开“设置”→“通用”→“关于本机”。
2. 确认机型、系统版本和设备名称。
3. 确认 Wi-Fi 已连接。
4. 检查是否出现激活锁、监管或异常提示。
5. 上传“关于本机”和 Wi-Fi 页面截图。

每一步只指导一个动作。截图遮住序列号、IMEI、Apple ID、邮箱、手机号和密码。遇到激活锁、刷机失败或监管提示时停止继续操作，整理原文和截图转人工。
