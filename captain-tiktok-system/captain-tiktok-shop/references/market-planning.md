# 市场与店铺模式选择

核对日期：2026-09-17。用于营业执照和注册之前确定目标市场、店铺模式与履约方式。默认课程主线是中国大陆主体申请 TikTok Shop 东南亚跨境自运营店；本土店、全托管和其他市场必须另查当期准入，不混用规则。

## 只确认四项

读取用户已有信息，缺少时只问会改变路径的问题：

1. 主体注册地和已有营业执照类型；
2. 计划销售的国家；
3. 是否自己选品、定价、做内容和承担运营；
4. 使用中国直发，还是已经在目标国备货。

## 选择顺序

1. 先查目标市场是否对当前主体和店铺模式开放；
2. 再查主营类目是否允许销售，是否需要定邀、认证或许可；
3. 核对结算、保证金、物流、退货和语言能力；
4. 估算价格带、竞争和完整贡献利润；
5. 最后确定一个首发市场、一个店铺模式和一个履约方式。

新手不要同时开多个市场。先跑通一个市场的上架、内容、订单、发货和退款，再评估复制。

## 模式判断

- 想自己控制选品、定价、内容、达人和广告：进入跨境自运营店规则；
- 想走全托管：重新读取全托管的招商、供货、定价、质检和履约规则，不套用本 Skill 后续自运营步骤；
- 想做本土店：先核对当地公司、税务、仓库、银行和负责人要求，不用中国跨境店资料替代；
- 尚未确定：默认先评估东南亚跨境自运营，不直接提交注册。

## 市场筛选表

| 维度 | 必查内容 |
|---|---|
| 准入 | 主体、店铺模式、类目和邀请要求 |
| 需求 | 搜索、成交、内容和季节趋势 |
| 竞争 | 价格、头部集中、达人和同质化 |
| 履约 | 直发/海外仓、运费、时效和退货 |
| 合规 | 禁限售、认证、标签和知识产权 |
| 经营 | 语言、客服、结算、汇率和税费 |

## 完成标准

用户能明确回答：做哪个国家、开什么模式、卖什么大类、从哪里发货。完成后进入营业执照与经营范围。

## 短版交互

> 开店前先定市场和模式。先确认：目标国家、跨境自运营还是其他模式、中国直发还是海外仓。
>
> 新手先跑通一个国家，不同时铺多个市场。
