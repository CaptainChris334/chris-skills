# 营业执照规则与来源

核对日期：2026-09-17。默认场景：中国大陆主体申请 TikTok Shop 跨境自运营店。不同注册地、本土店、全托管或平台招商活动必须另查。

## 直接给学员的规则

1. **只做东南亚：** 可以使用个体工商户营业执照申请。当前官方跨境自运营入驻资料把个体工商户主体限定在东南亚，不把这条规则套到其他店铺模式。
2. **准备长期做或申请多个市场：** 建议优先办理公司营业执照。这是课程建议，不是平台承诺。公司执照仍要按国家、站点、类目和当期招商要求审核，不能说“全球每一个国家都能开”。
3. **准备东南亚保证金：** 按每店 90 美元准备。不要说一张执照只交一次，也不要把它说成办执照费用或月费。
4. **确认豁免期限：** 平台存在新商保证金豁免权益，但本次没有取得能证明“所有东南亚新店统一免 90 天”的完整官方条文。看店铺后台的资格、起算日、到期日和应缴金额；没有后台证据就不要承诺 90 天。
5. **区分店铺结算与企业收款：** TikTok Shop 店铺回款使用卖家后台当前支持的结算工具；PayPal 中国企业账户注册材料包含营业执照，但它属于另一套企业收款产品。不要把 PayPal 写成东南亚店铺统一结算方式，也不要扩大成所有国家、所有 PayPal 账户都必须提供中国公司执照。
6. **区分独立站与收款：** 搭建网站不等于开通收款。用户选择平台和支付服务商后，再查对应注册地、主体与认证材料；不要说“所有独立站都必须公司执照”。

用户已有个体户并且只做东南亚时，先使用现有资格，不强迫另办公司。用户尚未办执照、计划长期经营多个市场或申请企业收款时，建议一步到位优先办公司营业执照。

## 查证规则

- 报金额、国家和活动期限前，核对当前官方正文、用户卖家后台或官方客服原文；保留适用市场、模式和日期。
- 搜索摘要能定位规则，但官方页面正文或卖家后台与摘要冲突时，以更具体、更新的官方信息为准。
- 媒体报道可作为查找线索，不能单独证明平台规则。当前不把“统一免 90 天”写成确定结论。
- 找不到明确规定时直接说尚未确认，并只给“查后台权益页或咨询官方支持”这一个动作。
- 用户只问选哪种执照时，不主动展开税费、注册资本、境外公司、开户和全球收款清单。用户追问后再查注册地官方资料。
