# 中转与服务商排障

## 概念

“中转”通常指在用户设备与最终出口之间增加一层或多层转发链路。它可能改善某些网络的可达性或路径质量，也可能增加延迟、故障点和排查难度。中转不是万能加速器，也不等于更高质量 IP。

## 购买前核验

只指导用户核验正规服务条款和售后能力：

- 明确支持的设备、协议、流量/带宽、并发数和退款规则。
- 确认是否提供测试节点、到期时间、故障工单和变更记录。
- 询问数据保留、隐私和日志政策。
- 不购买来路不明、要求远程控制设备、索要账号密码或承诺“100% 解封/0 播放必修复”的服务。
- 不代买、不代收验证码、不代登录 TikTok。

和工作人员沟通时，用可验证的技术描述：

```text
设备/系统：
客户端：
节点标签或线路编号：
普通网页是否可用：
出现问题的时间：
测试结果：
希望确认：节点状态、出口 IP、DNS、丢包/延迟、是否需要更换线路
```

## 手把手配置框架

1. 让服务商提供适配当前客户端的配置格式。
2. 用户本人导入配置，检查服务器、端口、传输方式、TLS/SNI 等字段是否齐全。
3. 先不开中转测试直连节点，再开启中转测试同一目标；记录两组结果。
4. 只比较一个节点、一个网站、一个时间窗口。
5. 若中转变慢或不通，恢复上一组可用配置，并把两组测试结果发给服务商。

“树洞”等具体产品如果出现，先确认其准确产品名、官网、支持系统和配置格式；不能仅凭昵称或群里口述指导下载。

## 中转故障分类

- 直连不通、中转通：可能是路径或网络可达性差，交给服务商确认。
- 直连通、中转不通：优先怀疑中转配置、端口、到期或中转节点故障。
- 两者都通但 TikTok 异常：进入 IP/账号/平台现象诊断，不继续叠加中转。
- 间歇性卡顿：记录时间、节点、延迟、丢包、抖动和切后台/锁屏后的变化，避免只说“很卡”。
